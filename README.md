# Interactive Birthday Card

Static HTML/CSS/JavaScript project inspired by the supplied PDF.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save.

The site will then be available through the GitHub Pages URL generated by GitHub.

## Change the passcode

Open `script.js` and change:

```js
const correctCode = '2911';
```

## Change the final message

Edit the text inside `#letterText` in `index.html`.

## Add your own photos

Replace `assets/photo.jpg` with your image, keeping the same filename, or change the `src` paths in `index.html`.
